# ร้านปลาย่าง 🍢

เกมร้านปลาย่างสำหรับไลฟ์ TikTok
ผู้ชมส่งของขวัญ → กลายเป็นตัวละครในร้าน (คนตกปลา / คนย่างปลา / ลูกค้า)

## วิธีรัน
    npm install
    node server.js ชื่อTikTokของคุณ
เปิด http://localhost:3000

ไม่ใส่ชื่อ TikTok ก็เล่นได้ ใช้ปุ่มของขวัญด้านล่างทดสอบ

## วิธีเล่น
- ปุ่ม ⚙️ บทบาท: เลือกว่าของขวัญเลเวลไหนเป็นคนตกปลา / ย่างปลา / ซื้อปลา
- ตกปลา → ตะกร้าปลาดิบ → ย่าง → เคาน์เตอร์ → ลูกค้าซื้อ (ได้ดวงปลา)
- ของขวัญเลเวลสูง = ปลาหายากกว่า, คนย่างเร็วกว่า
- ของขวัญคอมโบ (สูงสุด 5) = ทำซ้ำหลายรอบ
- ชื่อของขวัญ TikTok ที่ใช้จับคู่อยู่ใน data.js (match)
