# ศาลเจ้ามงคล (TikTok Live)

1. ติดตั้ง Node.js แล้วรัน `npm install`
2. รัน `node server.js ชื่อTikTokของคุณ` (ไม่ต้องใส่ @)
3. เปิด http://localhost:3000 แล้วแตะหน้าจอ 1 ครั้งเพื่อเปิดเสียง
4. ใช้ใน OBS / TikTok LIVE Studio: Browser Source ขนาด 720x1280
5. ทดสอบโดยไม่ต่อ TikTok: เปิด http://localhost:3000/?test แล้วแตะแถวของขวัญบนจอ
6. ชื่อของขวัญไม่ตรง: ดูบรรทัด GIFT: ใน terminal แล้วแก้ช่อง m ใน data.js
7. คนดูพิมพ์ปีเกิด (2540) หรือปีนักษัตรในแชต เพื่อให้ดวงตรงปี
